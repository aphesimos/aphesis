aφesis

Aphesis Script is the display hand of aphes.is: a lowercase-only humanist cursive written with the brush of the hand-drawn φ. {{GLYPH_COUNT}} glyphs, two axes, ten named instances. Every letter, figure, dot and dash is a brush stroke; nothing in it is a solid.

write

Type here. Capitals are accepted and set as lowercase: the face has none.

written, not stamped

Every letter exists in three drawings: the same skeleton written again by the same hand. A contextual rule cycles them 1 · 2 · 3 from the first letter of each word, so two neighbours are never the same drawing and a word always sets the same way.

the icon style

The site's icons are brush outlines filled with a scatter of small squares. Stylistic set 1 gives four symbols that treatment: the middle dot becomes a ring with grains inside, the asterisk gets dust between its rays, the number sign and the ampersand a dusted field. The same squares exist at every weight; they move and swell with the brush. It is an opt-in set (font-feature-settings: "ss01"), because at text sizes the grains turn to grey.

the family

One variable font, two axes. Ten named instances, each also cut as a static TTF and WOFF2. The φ follows the weight and never leans.

the signs

Oldstyle figures, because a face without capitals has nothing for lining figures to stand beside. Typed capitals map to the lowercase letters.

rhythm

The space beside a letter is measured on its ink, scanline by scanline, and every pair is set to enclose the same white. The control strings below are the ones the spacing was judged on; move the sliders and they stay even.

before, after

The original six-glyph font (grey) against the new one, on the strings from the first brief. Both follow the sliders. In the original the letters stood a stroke taller than the φ's loop and every advance width was a number typed in by hand, the same in every master.
