A small, kind hover for names: letters lift 2px one after another and the gloss turns red.

- **Provide** a link or button with class `aph-wave` containing the name; call `Aphesis.letters(nameElement)`. The element keeps its text as `aria-label`.
- **Use** for section names, chamber names and labels a person can choose. Not for running text.
- Nothing changes size or position around the word. Reduced motion turns it off.
