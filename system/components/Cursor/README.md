The only cursor: a disc in difference blend that is always the negative of what it covers.

- Call `Aphesis.cursor()` once per document. It does nothing on touch or coarse pointers.
- It opens to full size over `a`, `button` and `[data-cursor]`; set `data-cursor=".55"` (or any scale) on small controls, `data-cursor=".9"` on the corner seal.
- **Don't** add a second cursor style or bring the system cursor back on parts of the page.
